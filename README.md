# UMANG Chatbot Security Testing

This project contains two distinct workstreams:

1. `umang_pyrit_tests.py` — an initial set of six PyRIT LLM safety prompts (baseline plus five safety/privacy probes).
2. `umang_api_security_tests.py` — a conservative, low-rate API behavior extension covering basic validation, method handling, CORS observations, public/invalid-auth behavior, SQL-like input handling, inert HTML-marker reflection, and response headers.

**The initial six-prompt PyRIT run is not a complete VAPT assessment.** Review `API_VAPT_SCOPE.md` for limits and tests that need endpoint inventory, dedicated test accounts, staging, or explicit owner approval.

## Setup (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install pyrit httpx
```

If PyRIT is already installed in your environment, keep using the same virtual environment.

## Run PyRIT LLM safety probes

Only after the system owner has authorized the test scope:

```powershell
python umang_pyrit_tests.py --confirm-authorized
```

## Run API-level low-impact checks

Only after written authorization covers these exact endpoint checks:

```powershell
python umang_api_security_tests.py --confirm-authorized
```

The API script makes requests sequentially, without concurrency, defaults to 1.5 seconds between requests, and refuses delays below one second. It does **not** perform rate-limit exhaustion, active XSS execution, destructive SQL, credential guessing, or endpoint brute-forcing.

## Output

- PyRIT results/report: generated by `umang_pyrit_tests.py`.
- API JSON evidence: `results/api_security_results_latest.json`.
- API Markdown report: `reports/api_security_report_latest.md`.

The scripts produce evidence and preliminary triage only. Manually validate expected behavior, and do not report a confirmed vulnerability based only on status codes or marker matches.
